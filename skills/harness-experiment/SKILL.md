# Harness experiment

This skill is opt-in. Repeated failures or competing approaches may justify suggesting an experiment, but do not start one without an explicit user request.

Read and follow [`references/workflow.md`](references/workflow.md). It is the complete procedure and is packaged beside this skill; do not depend on another installed skill or repository file to run it.
